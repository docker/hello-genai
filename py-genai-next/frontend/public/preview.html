Everything a serious chat workspace needs

Not a toy wrapper — a full multi-user platform with the features you'd expect from a hosted product, running privately.

Realtime streaming

Token-by-token replies over WebSockets with visible reasoning, inline tool-call chips and live syntax highlighting — repainted once per animation frame so long answers stay smooth.

Persistent memory

Durable facts recalled across conversations via pgvector — extracted on a dedicated worker with a customizable prompt, semantically de-duplicated so rewordings never pile up, and live-updating with dismissible toasts.

RAG knowledge base

Upload txt/md/pdf; chunked and embedded into pgvector for grounded answers — scoped per project.

Vision & attachments

Attach images by paperclip, paste or drag-and-drop. Downscaled in the browser, sent as OpenAI image_url parts and persisted with the conversation.

DiceBear avatars

29 styles rendered offline by the backend — pick a seed, hit Surprise me, or tune background, radius, zoom, rotation and flip. Uploads get a full crop / zoom / rotate editor.

Yours to theme

13 accents, 6 duotone gradients, 8 typefaces, corner radius, density, chat width and reduce-motion — WCAG-AA checked and saved to your account, not the browser.

Agentic tools + web

Calculator, document retrieval, conversation search and live web search — called mid-reply only when needed.

Projects & branching

Scoped projects, conversation branching, edit & resend, full-text search and one-command export / import / backup.

Starred messages

Bookmark any reply and browse every star in one place, jumping straight back to its conversation.

Semantic search

Find a conversation you can describe but cannot quote — searching "authentication" surfaces a chat about JWT and password hashing that contains neither word. A Meaning toggle in ⌘K, with keyword still the default for exact strings.

Related conversations

Chats ranked by embedding centroid appear in a Related strip in the sidebar, with a similarity score — so older threads on the same topic resurface on their own.

Portable transcripts

Export any chat as JSON, Markdown, or a self-contained HTML file — no external assets, opens offline anywhere, and prints straight to PDF.

Compare models

Run one prompt across models side by side with a two-sided word diff, per-model token counts and ratings.

Blind model arena

Run one prompt across models with the names hidden, vote for the better answer, then reveal — and a win-rate leaderboard builds up in Analytics. Ties count as half a win.

Live analytics

A live dashboard: token hero, tokens/sec while generating, a 30-day trend with crosshair tooltips, ranked per-model bars and usage streaks.

Voice in & out

Dictate into the composer and have replies read aloud via the Web Speech API.

Works on your phone

Same-origin behind nginx, so it just works on any device on your network — installable as a PWA with an offline shell, 44px touch targets and a viewport-correct mobile layout.

Scheduled prompts

Recurring prompts run on Celery beat — a morning digest or standup summary lands in a fresh conversation.

OpenAI-compatible API

Point any OpenAI SDK at /v1 — chat/completions, models, models/{id} and embeddings — authenticated with a personal access token.

Admin & analytics

Per-model cost and latency, a live activity panel, and a role-aware admin console for user management.

A closer look

The same clean, shadcn-styled interface you'll use — workspace, model compare, and live analytics, with full light & dark themes.

Drop-in OpenAI API

Use it from Cursor, LangChain, a script, or any SDK. Your data never leaves your machine — the key is a personal access token you mint in the app.

Create a token → 
# same code, pointed at your machine
from openai import OpenAI

client = OpenAI(
  base_url="http://localhost:8080/v1",
  api_key="genai_pat_…",
)
resp = client.chat.completions.create(
  model="",
  messages=[{"role":"user",
             "content":"Hello!"}],
  stream=True,
)
