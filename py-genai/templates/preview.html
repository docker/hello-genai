Features
Everything you need

Built for developers who want a local AI chat environment without the cloud dependency.

Streaming Responses

Tokens appear as they're generated via Server-Sent Events — no waiting for the full response.

Persistent Sessions

Full conversation history stored in SQLite with WAL mode. Sessions survive restarts.

Smart Sidebar

Sessions grouped by Today / Yesterday / Last 7 Days / Older, with search filter, skeleton loaders, per-session model badge, and drag-to-resize.

Inline Session Rename

Double-click any session title in the sidebar to rename it in-place. Saves to the database instantly.

Multi-Model Support

Switch between any Docker Model Runner model at runtime. The model used per session is tracked and shown.

Model Settings

Temperature slider (0–2) and max-tokens control. Settings persist to localStorage and apply to every request.

System Prompt + Presets

Customise assistant behaviour per session. Named prompt presets are stored in the database and survive browser changes.

Compare Models

Send the same prompt to two models and watch both stream side by side. Only the primary response is saved to history.

Reasoning Models

Chain-of-thought from models like DeepSeek-R1 (<think> blocks) renders as a collapsible "thought process" section.

File Attachments

Attach a text or code file and its contents are added to your message as a fenced code block.

Context Trimming

Long conversations are automatically trimmed to a token budget before hitting the model — oldest turns first, so requests never overflow the context window.

Fully Offline

All JS/CSS/font assets are vendored locally — no CDN required. Works on an air-gapped machine, with a strict no-inline-script CSP.

Response Metrics

Each bot message shows time-to-first-token (ms) and tokens/sec alongside prompt/completion token counts.

Import & Export

Export conversations as Markdown or re-importable JSON. Import any JSON chat file ({ title, messages }) to restore a session.

Message Editing

Edit any past user message and regenerate from that point. History is truncated in the DB for consistency.

Regenerate Response

Re-run the last assistant response with one click — useful when the answer misses the mark.

Copy Code & Responses

Every code block has a language label and one-click copy. Bot messages have a full-response copy button too.

Response Feedback

Thumbs up / down stored per message. Review aggregate stats in the usage dashboard.

Full-Text Search

Search every conversation from the sidebar — message content is indexed with SQLite FTS5 and matches show highlighted snippets. ⌘F filters the current chat.

Scroll-to-bottom FAB

A floating button appears when you scroll up in a long conversation, snapping you back to the latest message.

Relative Timestamps

Message times show "just now", "5m ago", "2h ago". Hover for the absolute time.

Dark / Light Theme

Manual toggle with smooth CSS transitions. Code blocks adapt between GitHub light and dark syntax themes.

Usage Dashboard

Aggregate prompt, completion, and total token counts across all sessions.

Stop Generation

Interrupt a stream mid-response. Partial text is saved and marked with a "stopped" badge so you know it's incomplete.

Keyboard Shortcuts

⌘K new chat  ·  ⌘L clear  ·  ⌘/ sidebar  ·  ⌘F search  ·  Esc stop

Pinned Sessions

Pin important conversations to keep them at the top of the sidebar.

Auto-Title

Session titles are auto-generated by the model after the first exchange — no manual naming needed.

Quick Start
Up in three steps

Requires Docker Desktop with Docker Model Runner enabled.

1

Pull models

Pull the models you want to use locally.

docker model pull docker.io/ai/gemma4:latest
docker model pull docker.io/ai/gemma3n:latest
2

Start the app

From the repo root, start with Docker Compose.

docker compose up
3

Open the chat

Navigate to the app in your browser.

open http://localhost:8081
