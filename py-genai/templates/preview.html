What is a Docker container?
A container is a lightweight, isolated environment that packages an application with its dependencies. Unlike VMs, containers share the host OS kernel — making them fast to start and efficient.

Run one with: docker run hello-world

Features
Everything you need

Built for developers who want a local AI chat environment without the cloud dependency.

Streaming Responses

Tokens appear as they're generated via Server-Sent Events — no waiting for the full response.

Persistent Sessions

Full conversation history stored in SQLite. Sessions survive restarts and can be exported to Markdown.

Multi-Model Support

Switch between any Docker Model Runner model at runtime. Defaults configurable via AVAILABLE_MODELS.

System Prompt Editor

Customise assistant behaviour per session. Saved to the database and applied to every message in that session.

Message Editing

Edit any past user message and regenerate from that point. History is truncated in the DB for consistency.

Regenerate Response

Re-run the last assistant response with one click — useful when the answer misses the mark.

Response Feedback

Thumbs up / down stored per message. Review aggregate stats in the usage dashboard.

Message Search

Filter visible messages by keyword in real time. Dismiss with Esc.

Stop Generation

Interrupt a stream mid-response. Press Esc or click the stop button.

Auto-Title

Session titles are auto-generated by the model after the first exchange — no manual naming needed.

Usage Dashboard

Aggregate prompt, completion, and total token counts across all sessions.

Dark / Light Theme

System-aware default with manual toggle. Preference persisted to localStorage.

Keyboard Shortcuts

⌘K new chat  ·  ⌘L clear  ·  ⌘/ sidebar  ·  Esc stop

Export

Download any conversation as a Markdown file with one click.

Copy Code Blocks

Every code block in bot responses has a one-click copy button.

Pinned Sessions

Pin important conversations to keep them at the top of the sidebar.

Quick Start
Up in three steps

Requires Docker Desktop with Docker Model Runner enabled.

1

Pull models

Pull the models you want to use locally.

docker model pull docker.io/ai/gemma4:latest
docker model pull docker.io/ai/gemma3n:latest
2

Start the app

From the repo root, start with Docker Compose.

docker compose up
3

Open the chat

Navigate to the app in your browser.

open http://localhost:8081
