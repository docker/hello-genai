# java-husband

A tiny, lighthearted Java demo that models a "Husband" as an object with state
(name, age, mood, energy, spouse) and behaviors like `cook`, `doChores`,
`watchTV`, `bringFlowers`, `eat`, and `sleep`. Each method mutates the
husband's state and narrates what happens, and `main` runs through a short
"day in the life" so the program produces readable output.

It's a single, self-contained file with no external dependencies.

## Compile and run

```sh
javac Husband.java
java Husband
```

## Note

This is a just-for-fun demo, not a serious domain model. Enjoy!
